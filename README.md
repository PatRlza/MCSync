# MCSync 2.0

Программа для нашей компании: **админ собирает сборку Minecraft из своей папки и выкладывает её,
игрок нажимает одну кнопку и играет.** Ничего качать вручную, кидать в mods и вбивать IP не нужно.

### Бэкапы
- `Services/BackupService` следит за процессом Minecraft (`javaw`/`java`).
- Пока идёт игра — копия мира раз в N минут (по умолчанию 10), **только если мир реально менялся**.
- При выходе из игры — финальный снимок.
- Локально хранятся 8 последних копий: `%AppData%\MCSync\backups\<id сборки>`.
- Если указан токен — копия уезжает в релиз `backups` и попадает в манифест, админ качает её из раздела «Копии миров от игроков».
- Пока копия выгружается, **Windows не даст молча выключить компьютер** (`ShutdownBlockReasonCreate`), и программа переспросит при закрытии.

### Помощь при ошибках
Кнопка «Ошибка в программе или игре?» на превью → `Views/DoctorView`: 8 типовых проблем, и программа чинит сама:
мир не запускается → показывает копии с датами → ставит выбранную (сломанный мир не удаляется, а откладывается как `<мир>_broken_<дата>`);
вылеты → переустановка модов/конфигов; не видно сервер → проверка Radmin и стук в каждый сервер; Java; память; кривая загрузка.
«Другая проблема» → письмо на **a68590260@gmail.com** с темой «Ошибка в программе MCSync — <сборка>», в тело подставляется отчёт
(ОС, папка, лог MCSync, последний краш-репорт Minecraft), полный текст дополнительно кладётся в буфер обмена.

## Сборка: от исходников до установщика для рассылки

### 1. Поставить .NET 8 SDK
https://dotnet.microsoft.com/download/dotnet/8.0 → **SDK x64**. Проверка: `dotnet --version` (должно быть 8.x).

### 2. Собрать exe
Из папки проекта:

```
build.bat
```

или вручную:

```
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:EnableCompressionInSingleFile=true
```

Результат: `bin\Release\net8.0-windows\win-x64\publish\MCSync.exe` — один файл, .NET у игрока ставить **не нужно**.

### 3. Собрать установщик
1. Поставить **Inno Setup 6**: https://jrsoftware.org/isdl.php
2. Открыть `Setup\MCSync.iss` в Inno Setup Compiler → **Build** (F9).
3. Готово: `Setup\Output\MCSync-Setup.exe` — **это и есть файл для рассылки игрокам.**

Установщик по умолчанию ставит в `C:\Games\MCSync`, страницу выбора папки не прячет и подписывает её:
«если Minecraft уже стоит — можете указать папку своего лаунчера». Игру он не трогает, ставит только программу.

### 4. Подготовить репозиторий (один раз)
1. Создать **публичный** репозиторий на GitHub, ветка `main`.
2. Положить в корень файл `manifest.json`:
   ```json
   { "SchemaVersion": 2, "Packages": [], "Tools": [], "Backups": [] }
   ```
3. Сделать fine-grained токен: Settings → Developer settings → Personal access tokens → Fine-grained,
   доступ только к этому репозиторию, права **Contents: Read and write** и **Metadata: Read**.
4. Запустить MCSync → переключатель «Админ» → код **5913** → раздел «Подключение к GitHub»:
   владелец, репозиторий, токен → «Проверить доступ» (должно быть «Доступ есть ✓»).
5. Игрокам в их программе достаточно вписать владельца и репозиторий в «Настройки» — **токен им не нужен**.

## Важно про токен GitHub

Токен **нельзя** вшивать в exe, который вы раздаёте игрокам: из файла его вытаскивают за минуту любой
программой вроде `strings`, и дальше человек может стереть релизы, миры и сам репозиторий. Поэтому:

- `Services/Secrets.cs` по умолчанию с **пустым** токеном — так и оставляйте;
- админ вводит токен в интерфейсе, он лежит только на его компьютере в `%AppData%\MCSync\config.json`;
- чтение манифеста и скачивание сборок из публичного репозитория токена не требуют — игроки работают без него;
- если токен всё-таки где-то засветился — сразу отзовите его на GitHub и выпустите новый.

Тот токен, что вы начали писать в задании, лучше отозвать: он попал в переписку.

## Что стоит знать

- **Radmin VPN не имеет публичного API.** Список участников снаружи никак не читается. Поэтому «Найти участников»
  берёт адрес вашего адаптера Radmin и адреса из ARP-таблицы Windows (подсеть `26.x.x.x`) и пытается получить имена
  по DNS. Кого не нашло — добавляется вручную одной кнопкой. Это честный максимум без API.
- **Размер сборок.** Один файл в релизе GitHub — до 2 ГБ, сам релиз не ограничен. Для сборки с модами и миром этого хватает с запасом.
- **Пароль 5913** вшит как SHA-256 в `Services/Secrets.cs`. Смена кода в интерфейсе действует на конкретном компьютере;
  чтобы сменить «заводской» код для всех, поменяйте хеш в `Secrets.cs` и пересоберите (команда для генерации — в комментарии там же).
- **Проект не компилировался**: собирать WPF можно только на Windows с .NET SDK, у меня его под рукой не было.
  Все XAML проверены на корректность, но при первой сборке могут вылезти мелкие правки — пришлите текст ошибок, поправлю.
- **Логи** программы: `%AppData%\MCSync\logs\app.log`. Именно они уходят в письмо об ошибке.
- Внешних NuGet-пакетов нет вообще — сборка не сломается из-за интернета или версий библиотек.

## Структура

```
MCSync.csproj          проект (.NET 8, WPF, без зависимостей)
App.xaml(.cs)          запуск, конфиг, перехват любых ошибок
MainWindow.xaml(.cs)   рамка окна, переключатель Игрок/Админ, тосты
Themes/Theme.xaml      тёмная тема, все стили и анимации
Models/Manifest.cs     сборка, сервер, программа, бэкап
Services/              GitHub, установка, сборка пакета, пути Minecraft,
                       Radmin, бэкапы, помощь при ошибках, NBT servers.dat
Views/                 7 экранов: дом игрока, превью, мастер, доктор,
                       замок админки, дом админки, редактор сборки
Setup/MCSync.iss       установщик Inno Setup
build.bat              сборка exe одной командой
```
